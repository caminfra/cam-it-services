**Planned Users:** 2

### Finance

Responsible for accounting, financial operations, and financial record management.

**Planned Users:** 2

---

### Human Resources

Responsible for employee management, onboarding, offboarding, and personnel operations.

**Planned Users:** 2

---

### Operations

* Microsoft Entra ID user management
* Security groups
* Department-based access
* Microsoft Intune device assignments
* Role-Based Access Control (RBAC)
* Conditional Access policies
* Employee onboarding workflows
* Employee offboarding workflows
